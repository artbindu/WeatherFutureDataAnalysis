# download application
install python 3.6/3.7 version: *https://www.python.org/*<br>
install mongodb: *https://www.mongodb.com/*<br>
install Robo3T(GUI of MongoDB): *https://robomongo.org/*<br><br>

# python modules:
upgrad pip: `python -m pip install --upgrade pip`<br>
excel(input from excel): `pip install xlrd`<br>
mongodb(used database): `pip install pymongo`<br>
numpy(ANN calculation): `pip install numpy`<br>
matplotlib(draw graph): `pip install matplotlib`<br>

# How to Run:
open cmd: `python main.py`<br>
checkDB: `open 'MongoDB Compass Community' from your PC(Windows)` or `open 'Robo3T' after install it`
