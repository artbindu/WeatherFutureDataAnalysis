# download application
install python 3.6/3.7 version: *https://www.python.org/*\
install mongodb: *https://www.mongodb.com/*\
install Robo3T(GUI of MongoDB): *https://robomongo.org/*\\

# python modules:
 - [x] upgrad pip: `python -m pip install --upgrade pip`

 - [x] excel(input from excel): `pip install xlrd`

 - [x] mongodb(used database): `pip install pymongo`

 - [x] numpy(ANN calculation): `pip install numpy`

 - [x] matplotlib(draw graph): `pip install matplotlib`



# How to Run:
open cmd: `python main.py`

checkDB: `open 'MongoDB Compass Community' from your PC(Windows)` or `open 'Robo3T' after install it`

choose option
```text
        0. Exit

        1. Insert/Update Data from Excel Format to MongoDB

        2. Delete/Clear Data

        3. Predict Future Data with Both Approach
```
